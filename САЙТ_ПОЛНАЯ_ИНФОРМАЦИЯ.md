# 🌿 Эко-Календарь: Полная информация о сайте

## 📋 Общее описание

**Эко-Календарь** - это веб-приложение для отслеживания экологических праздников, мероприятий и природных объектов. Проект объединяет календарь экологических событий с интерактивной картой и погодной информацией.

### 🎯 Основная цель
- Информирование об экологических датах и праздниках
- Помощь в поиске природных объектов для мероприятий
- Предоставление погодной информации для планирования

---

## 🛠️ Технологический стек

### Backend
- **FastAPI** - Python веб-фреймворк
- **SQLite** - база данных
- **SQLAlchemy** - ORM для работы с БД
- **Pydantic** - валидация данных
- **Uvicorn** - ASGI сервер

### Frontend
- **HTML5** + **CSS3** + **JavaScript**
- **Leaflet.js** - интерактивные карты
- **2ГИС API** - российские карты и геолокация

### Внешние API
- **OpenMeteo** - погодные данные (бесплатно)
- **2ГИС** - карты и геолокация (требует API ключ)
- **Wikipedia** - изображения (бесплатно)

## 🗄️ База данных

### Таблицы

#### `holidays`
- `id` - первичный ключ
- `name` - название праздника
- `date` - дата проведения
- `description` - описание
- `type` - тип праздника (национальный, международный, региональный)
- `region` - регион празднования
- `image_url` - URL изображения

#### `work_days`
- `id` - первичный ключ
- `year` - год
- `month` - месяц
- `work_days_count` - количество рабочих дней

#### `users`
- `id` - первичный ключ
- `email` - email пользователя
- `name` - имя пользователя
- `password_hash` - хеш пароля
- `role` - роль (0 - пользователь, 1 - администратор)

### Начальные данные
- Загружаются через `seed.py`
- Включают основные экологические праздники
- Рабочие дни для календарей

## 🔌 API Эндпоинты

### Праздники
- `GET /api/holidays` - получить все праздники
- `GET /api/holidays/{holiday_id}` - получить праздник по ID
- `POST /api/holidays` - создать праздник (только админ)
- `PUT /api/holidays/{holiday_id}` - обновить праздник (только админ)
- `DELETE /api/holidays/{holiday_id}` - удалить праздник (только админ)

### Пользователи
- `POST /api/users/register` - регистрация
- `POST /api/users/login` - вход
- `GET /api/users/me` - текущий пользователь

### Внешние API
- `GET /api/external/weather` - погода
- `GET /api/external/locations/search` - поиск местоположений
- `GET /api/external/locations/nearby` - ближайшие парки

## 🌤️ Погода

### Источники данных
- **OpenMeteo API** - основной источник погоды
- **Климатические данные** - для прошедших/будущих дат

### Типы погодной информации
- **Текущая погода** - температура, влажность, ветер
- **Прогноз** - до 16 дней вперед
- **Исторические данные** - климатические нормы по месяцам

### Обработка запросов
```python
# Прогноз на конкретную дату
GET /api/external/weather?lat=55.75&lon=37.61&date=2024-06-05

# Прогноз на несколько дней
GET /api/external/weather?lat=55.75&lon=37.61&days=7
```
