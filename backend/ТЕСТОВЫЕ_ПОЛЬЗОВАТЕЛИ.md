# 👥 Тестовые пользователи Эко-Календаря

## 📋 Обзор

Для тестирования функциональности Эко-Календаря созданы два тестовых пользователя с разными правами доступа.

---

## 🔑 Учетные данные

### 🙋‍♂️ Обычный пользователь
- **Email**: `user@test.com`
- **Пароль**: `user123`
- **ID**: 1
- **Роль**: 0 (пользователь)

### 👨‍💼 Администратор
- **Email**: `admin@test.com`
- **Пароль**: `admin123`
- **ID**: 2
- **Роль**: 1 (администратор)

---

## 🎯 Права доступа

### Обычный пользователь (ID: 1)
- ✅ Просмотр всех праздников
- ✅ Поиск по фильтрам
- ✅ Использование карты
- ✅ Просмотр погоды
- ✅ Регистрация новых аккаунтов
- ❌ Создание праздников
- ❌ Редактирование праздников
- ❌ Удаление праздников
- ❌ Управление пользователями

### Администратор (ID: 2)
- ✅ Все права пользователя
- ✅ Создание новых праздников
- ✅ Редактирование существующих праздников
- ✅ Удаление праздников
- ✅ Просмотр списка пользователей
- ✅ Управление ролями пользователей

```python
# В Python
import sqlite3
from werkzeug.security import generate_password_hash

conn = sqlite3.connect('holidays.db')
cursor = conn.cursor()

# Удалить всех пользователей
cursor.execute("DELETE FROM users")

# Сбросить счетчик
cursor.execute("DELETE FROM sqlite_sequence WHERE name='users'")

# Создать тестовых пользователей
users = [
    ('user@test.com', 'Тестовый пользователь', generate_password_hash('user123'), 0),
    ('admin@test.com', 'Администратор', generate_password_hash('admin123'), 1)
]

cursor.executemany(
    "INSERT INTO users (email, name, password_hash, role) VALUES (?, ?, ?, ?)",
    users
)

conn.commit()
conn.close()
```

## 📊 Структура пользователей

### Таблица users
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    email TEXT UNIQUE NOT NULL,
    name TEXT NOT NULL,
    password_hash TEXT NOT NULL,
    role INTEGER DEFAULT 0
);
```

## 🐛 Отладка

### Проверка пользователей
```python
# Скрипт проверки пользователей
import sqlite3

def check_users():
    conn = sqlite3.connect('holidays.db')
    cursor = conn.cursor()
    
    cursor.execute("SELECT id, email, name, role FROM users")
    users = cursor.fetchall()
    
    print("Текущие пользователи:")
    for user in users:
        role_text = "Администратор" if user[3] == 1 else "Пользователь"
        print(f"ID: {user[0]}, Email: {user[1]}, Имя: {user[2]}, Роль: {role_text}")
    
    conn.close()

check_users()
```

### Сброс паролей
```python
# Сброс паролей к значениям по умолчанию
import sqlite3
from werkzeug.security import generate_password_hash

def reset_passwords():
    conn = sqlite3.connect('holidays.db')
    cursor = conn.cursor()
    
    # Сброс пароля пользователя
    cursor.execute(
        "UPDATE users SET password_hash = ? WHERE email = ?",
        (generate_password_hash('user123'), 'user@test.com')
    )
    
    # Сброс пароля администратора
    cursor.execute(
        "UPDATE users SET password_hash = ? WHERE email = ?",
        (generate_password_hash('admin123'), 'admin@test.com')
    )
    
    conn.commit()
    conn.close()
    print("Пароли сброшены к значениям по умолчанию")

reset_passwords()
```

## 📞 Поддержка

### Проблемы с входом
1. **"Неверный пароль"** - проверьте раскладку клавиатуры
2. **"Пользователь не найден"** - запустите `reset_users.py`
3. **"Ошибка сервера"** - проверьте работу бэкенда

### Проблемы с правами
1. **"Нет доступа"** - проверьте роль пользователя
2. **"Кнопка отсутствует"** - войдите как администратор
3. **"API ошибка"** - проверьте JWT токен
